# ERAG 企业级知识库助手

ERAG 是一个企业级 AI 知识库助手平台，基于 RAG（检索增强生成）技术。

## 核心功能

1. **混合检索**：结合向量搜索和 BM25 关键词搜索，通过 RRF 融合算法提升检索质量
2. **Agent 引擎**：支持多步骤推理的自主 Agent，包含 Planner、Knowledge、Analysis、Report 四个阶段
3. **工作流引擎**：声明式流程编排，支持人工审批节点
4. **知识治理**：文档去重、质量评分、生命周期管理
5. **AI 运维**：调用追踪、费用分析、阈值告警

## 技术栈

- 后端：Spring Boot 3.5 + LangChain4j 1.18
- 前端：Vue 3 + TypeScript + Element Plus
- 向量库：Milvus 2.4
- 词法检索：Elasticsearch 8.13
- 消息队列：RabbitMQ 3.13
- 缓存：Redis 7.4

## 部署方式

支持 Docker Compose 一键部署，包含 11 个服务容器。
