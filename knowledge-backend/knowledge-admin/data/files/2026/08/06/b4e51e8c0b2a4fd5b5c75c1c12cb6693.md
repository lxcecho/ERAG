# ERAG 企业级知识库助手
ERAG 是一个企业级 AI 知识库助手系统，采用 Java 17 与 Spring Boot 3 开发。
核心功能：
- 多租户隔离：每个租户拥有独立的数据空间与访问控制；
- 多知识库管理：支持创建多个知识库，按主题隔离文档；
- 文档解析：支持 Markdown、Word、PDF 等格式，自动切片向量化；
- RAG 混合检索：结合向量检索与关键词检索，返回带引用来源的答案；
- 自定义 Agent：可配置系统提示词与多步骤流程，支持知识库检索与日志分析；
- 记忆中心：Agent 具备跨轮会话记忆、摘要记忆与长期事实记忆能力。
HDMI 高清多媒体接口是数字音视频传输标准，与 ERAG 知识库无关。
