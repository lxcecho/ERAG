# HDMI 知识库助手 — 简历内容

---

## 项目技术

Spring Boot / LangChain4j / Milvus / Elasticsearch / RabbitMQ / Redis / MySQL

---

## 项目描述

HDMI 企业级 RAG 知识助手系统。支持 PDF/Word/Markdown 文档上传至知识库，系统自动完成文档解析、智能切片、向量化存储，用户通过自然语言提问即可获得**有据可查**的精准回答。

---

## 工作内容

### 1）文档解析与双路存储流水线
设计并实现文档从上传到向量化的完整入库流水线。通过 **RabbitMQ 异步派发**解析任务（含重试、死信队列、幂等消费、定时补偿），调用 **MinerU** 引擎将 PDF 转为结构化 Markdown；按**标题层级切分**并附加面包屑元数据，保证每个片段语义完整。切片后通过 Embedding 模型向量化，同时写入 **Milvus**（向量检索）和 **Elasticsearch**（BM25 全文检索），实现双路存储。

### 2）混合检索与 RRF 融合精排
实现**向量 + BM25 双路召回**，通过 **RRF（Reciprocal Rank Fusion）** 融合排序——基于排名而非分数，天然解决不同引擎分数量纲不可比的问题；再经 **Cross-Encoder（BGE-Reranker）** 精排，兼顾召回率与精确度。任一路异常自动降级单路，保证可用性。

### 3）RAG 优化流水线
构建检索前后多环节优化：**查询改写**（LLM 将口语化问题转为精确检索查询）、**Multi-Query 扩展**（多角度子查询分别检索后跨查询 RRF 融合）、**上下文压缩**（去除检索片段冗余噪声）、**语义缓存**（相似问题直接命中缓存，节省 LLM 调用成本）。

### 4）多 Agent 协作引擎
设计并实现基于 DAG 的多 Agent 任务系统，含 Planner / Knowledge / Analysis / Report 四角色协作。Agent 无状态设计（Spring 单例 + Context 传递产物），工具通过 **SPI 机制自动注册**（JSON Schema 参数校验 + 权限控制）。支持**线性流水线**（4 步顺序执行）和**图编排模式**（节点级重试 + 硬超时 + Saga 补偿回滚）两种执行方式。

### 5）声明式工作流引擎
实现声明式工作流引擎，支持 **TOOL / LLM / HUMAN** 三种节点类型。HUMAN 节点实现**人工审批门**（流程暂停等待审批后继续），每节点执行后持久化 context_json 实现**崩溃断点恢复**，节点级自动重试保障执行可靠性。
